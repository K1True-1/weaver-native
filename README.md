# 织律者 · 原生桌面 Demo 0.4.0

Godot 原生桌面卡牌游戏。此版本集中实现真实敌方牌组、可读的逐张出牌过程，以及卡牌拖拽和音画反馈。

## Windows 试玩

解压 Windows 压缩包，双击 `Weaver.exe`。资源已内置，无需浏览器、Node.js 或 Godot 编辑器，游玩不需要联网。

目标平台：Windows 10 / 11，64 位，支持 OpenGL 3.3 的显卡及驱动。临时测试构建，尚未签名。

建议先进入「规则练习」：提供十张固定卡牌、三个规则槽和一个可破坏物件，独立于正式冒险。按空格结束回合，即可观看敌人抽牌、翻牌、发动效果与弃牌。

## 本次调整

### 对手真正使用卡牌

- 每个敌人拥有实体卡牌组成的牌组、抽牌堆、手牌和弃牌堆；出牌必须实际持有卡牌并支付费用。
- 普通敌人 8 张牌，精英 9 张，首领 10 张。不同敌人的攻击、防御、强化及物件利用倾向不同。
- 初始手牌 3 张，每次行动阶段补至至少 5 张，至少抽 2 张，上限 7 张；未打出的手牌保留，牌库耗尽后洗回弃牌。
- 每回合恢复 3 点行动能量，最多打出 3 张牌。对手根据生命、护甲、组合条件、剩余费用及场景物件选择合法出牌。
- 上方卡背对应真实手牌；逐张抬起、翻面、展示牌面、发动效果，再飞入弃牌。伤害、护甲和命中声音按效果时序结算。
- 点击敌人切换查看其手牌数量、费用、整套牌组与弃牌；不公开隐藏手牌内容和抽牌顺序。
- 保留玩家连续手动出牌的完整回合，原有规则组装、连锁和随机物件仍然生效。

### 拖拽与反馈

- 保持按下位置与指针的对应关系，拖动不会把牌突然吸到鼠标中心。
- 卡牌倾斜和尺度使用弹簧响应；悬停、相邻让位、无效落点返回与手牌整理保留运动惯性。
- 手内拖动可调整顺序；卡牌出手后，相邻手牌自然合拢。
- 松手施放包含短暂蓄势、加速飞行、落地压缩和过冲回弹；抽牌错峰进入手牌。
- 敌人攻击具有准备、前冲和回位；投射物、命中闪光、数字、生命条与合成音效分阶段呈现。
- 提供快速结算、减少动效和音效开关。

## 鼠标与快捷键

- 悬停查看手牌；点击选牌再点击目标，或直接拖到敌人、自己、物件上。
- 无目标卡可点击「施放」，或拖到战场中央。
- 将手牌拖入左侧空规则槽，选择触发条件和执行目标，然后确认安装。
- 点击已安装规则，可设置目标、预留能量、暂停规则，或拆出后手动打出。
- 点击物件查看用途；敌我共享物件的充能。
- 数字键 1–9 选牌，Enter 施放无目标卡，空格结束回合，Esc 取消选择，F11 切换全屏。

## 第一条组合

在练习中把「短击」安装到「施术之后」，目标选择敌人。手动打出「蓄能」或防御牌，即可看到规则响应攻击。

安装占用实体卡并支付能量；后续响应也支付能量。每回合首次成功响应减免 1 能量。每个节点重新组装，整局获得的卡牌保留在卡组中。

## 冒险内容

- 三章分支冒险；战斗、精英、首领、商店、休息、事件、宝藏节点。
- 30 种玩家卡牌、8 种触发条件、12 种物件、10 种遗物、15 种敌人定义。
- 卡牌升级、删牌、抽牌与检索；水平解锁起始卡组和路线。
- 合法连锁可以继续；每 200 次响应暂歇，避免无限循环锁死操作。

冒险自动保存至本机 Godot 用户数据目录；练习不覆盖冒险。0.3 原生版稳定存档可载入，旧敌人数据会初始化为真实牌组。不导入 H5 存档。

本版仍为玩法与动效验证版本；敌方牌组的强度以及一局 40–60 分钟的目标需要试玩校准。

## 验证范围

玩法引擎通过原有 192 项检查；新增敌方牌组检查 949 项，覆盖费用、卡牌流转、AI 合法操作、组合条件、物件互动、洗牌及存档迁移。卡牌运动通过 25 项检查，特效通过时序和清理检查。

已在 Linux 原生 OpenGL 窗口使用真实鼠标事件验证拖拽攻击和结束回合：抓持点在两个停稳位置保持一致；敌人抽牌、攻击、防御、弃牌后交回玩家回合，无运行时错误。

Windows x64 程序已导出并检查可执行文件格式。当前环境无法启动 Windows 程序，尚未进行 Windows 实机兼容性或显卡帧率测试。

随附动效视频由原生引擎以固定 60fps 逐帧渲染，包含游戏生成的声音；没有插帧，不代表 Windows 实时性能。实际窗口验证使用软件渲染，约 7–16fps，不作为目标设备的帧率依据。

## 源码与构建

使用 Godot 4.7.2 标准版打开 `project.godot`，无需第三方插件。安装相同版本的官方导出模板后，使用项目自带 Windows Desktop 或 Linux Desktop 预设。

```sh
godot --headless --path . --script tests/engine_test.gd
godot --headless --path . --script tests/enemy_deck_test.gd
godot --headless --path . --script tests/card_motion_test.gd
godot --headless --path . --script tests/vfx_test.gd
godot --headless --path . --export-release "Windows Desktop" /absolute/output/Weaver.exe
```

使用 `-- --showcase` 可运行固定练习演示，不覆盖冒险存档。资源、脚本、字体及第三方许可均随源码附带。
