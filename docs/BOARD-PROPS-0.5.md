# 战场实体摆件素材与交互

使用 Codex 内置 ImageGen 生成（未使用外部 API）；背景图仅作为材质与照明参考。素材保存在 `assets/props/o01.png` 至 `o08.png`，原母版保留透明通道。运行时缩放与裁切透明边缘，不覆盖素材母版。

八种战斗物件对应折光晶柱、蓄能晶簇、记忆石碑、雷鸣瓶、余烬炉、潮汐槽、裂纹圣像、引信箱。它们是带动画与材质反馈的 2.5D 摆件，不是实时三维模型。非战斗服务页的 O09–O12 未在本轮重绘。

空手左键播放微动、短音效及局部粒子 / 涟漪；悬停查看规则。选中卡牌时点击或拖放仍执行原有游戏规则。装饰性点击不会改动游戏随机数、生命、能量或物件充能；连点有冷却，不可通过点击免费获得战斗奖励。击碎残片使用原摆件纹理。透明区域不接收点击。
