# 织律者 · 规则之外 v0.5.0 试玩版

本版先保存当前进度，供下载试玩与继续迭代，**不是正式商业发行版**。

## 画面与交互

- 敌上我下的纵向战场；角色姓名框移除，生命宝石只显示当前血量。
- 暗青石板、旧铜按钮、羊皮纸卡牌；规则槽、导航及牌堆减少常驻文字。
- 主角与灰刃全身立绘、召唤阵、呼吸微动、背景暗角、施法与重击反馈。
- 8 种无框实体摆件，带落地阴影、点击微动、晶光 / 电弧 / 火星 / 水波及材质音效。
- 空手点击摆件只播放装饰反馈；出牌仍正常扣费、伤害、修复与结算物件奖励。
- 分叉羊皮纸地图、已走路径和后续路线预览。

## 下载与运行

下载下方 **Weaver-Windows-0.5.0-Board.zip**，完整解压后运行 `Weaver-Windows-0.5.0/Weaver.exe`。不需要安装 Godot。

进入「规则练习」可直接体验新版战场和右侧晶柱互动。源代码另在仓库中；GitHub 自动生成的 Source code 包不是可运行游戏包。

Windows x64，离线运行。程序尚未签名；不要为运行它关闭系统安全防护。

## 验证与限制

1,514 项自动检查通过；另通过动效检查、游戏视口鼠标点击测试，以及独立 Windows 程序的物件互动、破坏奖励、敌方回合与地图验证。已在 RTX 5070 Ti 本机运行，未完成跨设备与长期游玩验收。

角色和物件为 2.5D 图层与动画，不是实时三维模型；部分卡图、敌人和非战斗服务物件仍有复用。音乐、更多专属美术、平衡与正式上线材料仍待迭代。

新存档目录：`%APPDATA%/Weaver/Native-0.5`，不覆盖旧版存档。v0.4.0 与原仓库历史保留。
